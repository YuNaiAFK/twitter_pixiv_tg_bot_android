# v1.10 — Pixiv GIF 顯示為可下載文件

發佈日期：2026-11-07；版本 `1.10`、APK `versionCode=15`。

修正 Telegram Desktop 仍將 Pixiv GIF 文件顯示成動畫卡片的問題。Bot API 的診斷回傳雖是文件，MIME 仍為 `image/gif`；桌面端會依此顯示動畫。現在改用 MTProto，以 `application/octet-stream` 及強制文件旗標傳送，保留 `.gif` 檔名、原始解析度、全部影格與檔案內容。新解析、快取重送皆使用相同方式。

已實際傳送經管理員同意的驗證訊息，確認 Telegram 回傳一般文件 MIME、沒有動畫屬性；管理員也已確認桌面端顯示為所需的文件樣式。Windows、Android 各 39 項相關離線測試通過；手機含 R2 的 52 項檢查全部通過，App、面板與 bot 已同步更新至 v1.10 並正常啟動。

需要 Telethon 與 python-socks[asyncio]；手機安裝腳本與 Windows requirements.txt 已更新。沿用 `.env` 的 `TELEGRAM_API_ID`、`TELEGRAM_API_HASH`、`BOT_TOKEN`，工作階段位於 `.mtproto/`，不納入 Git。程式會檢查工作階段與 bot 身分一致，並以固定 random_id 避免同次請求重複傳送；失敗不會降回 Bot API 動畫模式。
