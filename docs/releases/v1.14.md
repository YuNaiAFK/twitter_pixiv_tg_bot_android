# v1.14 — Telegraph 製作日期與個人文字連結記憶

2026-11-09；版本 `1.14`、APK `versionCode=24`。

本機圖片／ZIP／CBZ 製作 Telegraph 新增「頁面文字（記憶）」及「文字連結（記憶）」選項。標題下方顯示製作日期與發送者自訂文字，再依檔名順序放圖片。有提供網址時自訂文字為超連結；只有文字時為普通文字，只有網址時顯示「連結」。Telegraph 原生作者欄也會使用自訂文字第一行（最多 128 字）與連結，對應標題下方的作者資訊。

日期按建立頁面的當天以 UTC+8 自動產生；文字最多 2000 字，連結限完整 HTTP(S) 網址。兩項設定依發送者個別保存於 `local_upload_profiles.json`，下一份作品及重啟後自動沿用，不提交 GitHub。可重新設定或個別清除；取消作品不清除記憶。原有作者／E站的當批 Telegram 連結保持獨立。

新增四項離線測試，涵蓋日期／連結文字在標題與圖片之間、Telegraph 原生作者欄、跨使用者隔離、重啟後沿用及清除。Windows 110 項相關回歸測試通過（2 項環境條件略過）。未建立公開測試頁面或傳送測試訊息。

手機 110 項相關測試也通過（Windows Docker 案例略過），程式已同步並重新啟動，管理 App 與面板確認為 `1.14 / 24`。

既有安裝須同步 Python 程式並重新啟動 bot；僅安裝管理 APK 不會更新執行中的程式。
