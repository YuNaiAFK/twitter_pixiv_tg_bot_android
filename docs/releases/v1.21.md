# v1.21 — 頻道歷史連結去重

2026-11-09；版本 1.21、versionCode=34。

Twitter 與 EH 確認發布時，先檢查所選頻道既有訊息，包括文字、圖片說明及隱藏超連結。已有相同連結則不重複發布，並顯示既有訊息編號。不同頻道各自比對，並序列化同頻道的檢查與發送，避免同時操作造成重複。

相同 Twitter 作品的網域別名及追蹤參數、e-hentai／exhentai 同畫廊網址會視為同一連結。直接讀取頻道歷史，不只檢查更新後 bot 發送的記錄。

沿用 bot MTProto 憑證與工作階段；不需個人帳號登入。歷史訊息較多會增加檢查時間；分批讀取並遵守 Telegram 的限流等待，無法完成檢查則不發送。

既有管理員、私聊、EH 僅「Telegraph · 顯示圖」成功顯示封面及逾時不發送規則不變。既有安裝須同步 Python 程式並重新啟動。
