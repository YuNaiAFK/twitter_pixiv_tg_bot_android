# v1.15 — 群組回覆壓縮檔製作 Telegraph

2026-11-09；版本 `1.15`、APK `versionCode=25`。

在已授權群組中，回覆 ZIP／CBZ 訊息並輸入 `/publish@機器人名稱`，bot 才會接收該檔案並提供與私聊相同的設定與上傳確認選單。直接傳送壓縮檔不會自動製作；圖片及圖片文件製作仍限私聊。

群組支援作者／E站連結、頁面文字及連結記憶、製作日期、1280px 圖片、封面、自然排序、R2 去重與失敗重試。記憶設定依指令發起者保存，與該帳號的私聊共用；各聊天及各發起者的待製作檔案獨立。設定內容須回覆 bot 指定輸入提示，普通聊天與其他成員的回覆不會套用。重複回覆同一個已接收檔案只重顯選單，不重複加入。

按「上傳並製作」或對已接收批次使用 `/publish@機器人名稱` 開始上傳；`/cancel_upload@機器人名稱` 取消。保留原有群組授權與指令需指名 bot 的規則。

新增三項群組離線測試，涵蓋回覆壓縮檔到確認製作完整流程、拒絕圖片／未授權群組、發起者需回覆指定提示才能設定文字。Windows 113 項相關回歸測試通過（2 項環境條件略過）。未傳送真實群組測試訊息或建立公開測試頁面。

手機 113 項相關測試也通過（Windows Docker 案例略過），程式已同步並重新啟動；管理 App 與面板確認為 `1.15 / 25`。

既有安裝須同步 Python 程式並重新啟動 bot；僅安裝管理 APK 不會替換執行中的程式。
