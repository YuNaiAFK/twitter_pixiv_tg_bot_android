# v1.10.2 — 支援匿名群組管理員

2026-11-07；版本 `1.10.2`，APK `versionCode=17`。

辨識 Telegram 以本群 `sender_chat` 表示的匿名管理員，讓匿名管理員可在群內使用不帶參數的 `/grant`、`/revoke` 授權或移除本群。匿名管理員不會被提升為 bot 全域管理員，不能操作其他 ID 或執行重啟、憑證、全域名單等命令。其他頻道代發及自動轉發不會取得這項權限。

9 項權限測試涵蓋本群、跨群、轉發、匿名身分不含使用者 ID 以及既有管理員權限，並確認匿名回覆不會包含全域名單，撤銷最後一群也不會開放所有群組。Windows、Android 與手機同步更新。
