# v1.13 — 管理員確認傳送 X／Twitter 結果到頻道

2026-11-09；版本 `1.13`、APK `versionCode=23`。

管理員在私聊解析 X／Twitter 成功後，新增頻道傳送確認按鈕。可選擇一個已登記頻道或「不傳送」；5 分鐘未操作預設不傳送，逾時按鈕失效。一般使用者照常解析，不會顯示按鈕；群組及其他解析類型不觸發。新解析與快取重送均支援。

以 bot 管理員身分把 bot 加入頻道並授予「發布訊息」權限後自動登記。管理員可用 `/channels` 查詢、`/channels @頻道名稱` 或 `/channels -100頻道ID` 手動登記，`/channels remove -100頻道ID` 移除。

確認後複製該次已送出的媒體與說明，保留相簿及來源連結，不重新下載，不包含狀態訊息。再次檢查管理員與發布權限，選項限發起者於原私聊使用。快速連點不會重複發布；部分失敗或逾時會要求先檢查頻道，不自動重送。bot 離開頻道或失去發布權限時移除登記。頻道設定不提交 GitHub；待確認選項不跨重啟保存、不補發。

新增 10 項離線測試，包含一般使用者、群組與 Pixiv 無按鈕，確認／拒絕／逾時、重複點擊、權限撤銷、多頻道、登記保存，以及實際新解析與快取流程。Windows 106 項相關測試通過（2 項環境條件略過）。未傳送真實頻道測試訊息。

手機 106 項相關測試也通過（Windows Docker 案例略過），已同步程式、重新啟動 bot；管理 App 與面板確認為 `1.13 / 23`。

既有安裝需要同步 Python 程式（含新的 `bot/channel_publish.py`）並重新啟動；只安裝管理 APK 不會替換程式。
