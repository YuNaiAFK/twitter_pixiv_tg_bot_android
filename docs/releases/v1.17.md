# v1.17 — 本機檔案製作僅限管理員

2026-11-09；版本 `1.17`、APK `versionCode=27`。

本機圖片／ZIP／CBZ 製作 Telegraph 的私聊與群組入口改為僅限 bot 設定中的管理員。非管理員傳檔、使用 `/publish`、`/cancel_upload` 或點選舊製作按鈕時靜默忽略，不下載檔案、不建立暫存、不上傳，也不顯示拒絕訊息；按鈕僅以空回應結束等待動畫。

公開及所有私人聊天的指令選單移除製作／取消指令，僅保留在管理員專屬選單。`/start`、`/help` 依目前管理員身分顯示製作說明。撤銷管理員時清除該帳號的專屬選單；舊選單與按鈕也會在操作時重新檢查權限。

一般使用者的 Twitter、Pixiv、e-hentai 連結解析權限維持原有規則，包含圖片說明中的作品連結。管理員的群組製作仍須符合群組授權與指名 bot 的指令規則，沿用單則操作訊息、設定記憶、日期、R2 去重與重試。

新增四項離線測試，涵蓋非管理員靜默且不下載、權限撤銷後不能續用、一般連結仍解析，以及公開選單與說明不顯示指令。Windows 122 項相關回歸測試通過（2 項環境條件略過）；未傳送真實測試訊息。

手機 122 項相關測試也通過（Windows Docker 案例略過），程式、說明與選單已同步並重新啟動；管理 App 與面板確認為 `1.17 / 27`。

既有安裝須同步 Python 程式並重新啟動 bot；只安裝管理 APK 不會更新執行中程式。
