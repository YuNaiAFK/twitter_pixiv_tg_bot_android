# v1.9 — Pixiv 動圖與 R2 上傳改善

發佈日期：2026-11-07。Android App、控制面板與腳本共用版本 `1.9`，APK 的 `versionCode` 為 `12`。

- 訊息自動清理只刪除 bot 送出的處理提示，保留使用者貼出的原始訊息。
- R2 上傳失敗時通知使用者並自動重試；連續三輪失敗後提供繼續／停止選項。選擇停止會中止該次 e-hentai 解析。相同內容會重用既有檔案，避免重複上傳。
- Pixiv 檔名統一為 `作品名稱_作品ID_p頁碼_畫師ID_畫師暱稱.ext`，每張頁碼從 `p0` 開始，快取重送也保留檔名。
- 修正 Pixiv Ugoira 下載為 ZIP 後無法傳送的問題。依 ZIP 內的影格與 Pixiv 播放資料合成 GIF，保留來源解析度與全部影格，不縮圖、不刪幀、不合併相同影格。GIF 本身每幀最多 256 色，播放時間以 10 毫秒為單位。
- GIF 超過 Telegram 的動畫傳送限制時，改傳同一個 GIF 文件，不額外壓縮或包成 ZIP。舊版 Ugoira ZIP 快取會重新下載並轉換。

本次手機實測作品 `135063022`：轉換前後皆為 `448×720`、`50` 幀，每幀播放時間一致。Pixiv 相關 30 項離線測試在 Windows、Android 專案及手機上皆通過；發佈前另於手機執行 Pixiv 與 R2 共 43 項測試，全部通過。APK 已完成建置與簽章驗證，手機 App 與面板皆確認為 `1.9`，bot 正常執行。

`bot-panel.apk` 的 SHA-256：`bb5b7dfcf349298b65651c533d24221388358dbfcc1920bd48ba81e20dbf3231`。

`bot-panel.apk` 是管理 App；bot 的 Python 程式與腳本位於本版原始碼。既有 Termux 安裝也需要同步專案程式、`VERSION.properties` 並重新啟動 bot，單獨安裝 APK 不會替換 Termux 裡的 Python 程式。既有設定、Cookie 與快取應予保留。

Release 同時附上 `termux.apk`、`termux-api.apk` 與 `termux-boot.apk`；這三項沿用既有安裝套件，已安裝者無須重裝。
