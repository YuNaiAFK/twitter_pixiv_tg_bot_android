# v1.9.1 — Pixiv 一律傳送文件

發佈日期：2026-11-07。版本 `1.9.1`，APK `versionCode=13`。

- Pixiv 的靜態圖片、GIF 與影片一律以文件傳送；新解析及快取重送使用相同規則。
- Ugoira ZIP 轉換完成後直接傳送 `.gif` 文件，保留原始尺寸與全部影格，不額外縮圖、刪幀或壓縮。
