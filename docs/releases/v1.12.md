# v1.12 — 私聊上傳確認與可選來源連結

2026-11-09；版本 `1.12`、APK `versionCode=22`。

本機圖片／ZIP／CBZ 製作 Telegraph 改為僅限私聊。群組圖片不會進入本機製作流程，原有圖片說明中的連結解析保持可用；製作與取消指令只出現在私聊選單。

傳送檔案後先暫存，顯示「上傳並製作」「取消」「作者連結」「E站連結」。按上傳或輸入 `/publish` 才開始上傳 R2。多張圖片仍可累積，未確認前不會建立頁面。

點選作者或 E站後，依提示傳送完整 HTTP(S) 網址；可按「略過／移除連結」。完成訊息保留第一張圖片封面與標題，「即時預覽」連至 Telegraph；作者與 E站有填網址時是超連結，未填時是普通文字。連結只適用本批作品，不自動沿用至下一批。

上傳選項依使用者及作品識別，其他使用者或舊作品的按鈕不能啟動新批次。沿用 1280px 預覽、檔名自然排序、R2 去重及失敗重試。

新增五項互動測試，包含等待上傳選擇、填入兩個連結、略過與非法連結、過期／他人按鈕、群組不處理。Windows 的 96 項相關回歸測試通過（2 項環境條件略過）；所有外部傳送均以替身驗證。

手機上的 96 項相關測試也通過（Windows Docker 案例略過），程式已同步並重新啟動；管理 App 與面板確認為 `1.12 / 22`。

既有安裝需要更新 Python 程式並重新啟動 bot；僅更新管理 APK 不會替換執行中的程式。
