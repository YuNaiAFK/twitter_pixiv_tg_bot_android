# v1.16 — Twitter 來源超連結與單訊息製作流程

2026-11-09；版本 `1.16`、APK `versionCode=26`。

Twitter 解析結果的「原始連結」改為可點選文字，網址嵌入 Telegram 文字實體，不再直接顯示完整網址。套用於單圖、影片、GIF、文件與相簿的來源說明，包含快取重送；複製到頻道時一併保留超連結。其他平台及 Pixiv 文件方式維持原有行為。

本機圖片／ZIP／CBZ 製作 Telegraph 改為每批僅建立一則 bot 操作訊息。後續檔案接收、選單、文字與連結輸入提示、錯誤、上傳進度均編輯同一則訊息；完成時直接把它轉為第一張封面與結果連結，不另發完成訊息，也不刪除該封面。

群組設定文字或連結時，請由發起者回覆同一則操作訊息；提供清除／略過與返回選單按鈕。取消與重試也沿用原操作訊息。個人記憶、製作日期、R2 去重與失敗重試保持可用，使用者的原始檔案與輸入訊息不自動刪除。

新增四項 Twitter 超連結測試及一項完整單訊息互動測試，包含 Unicode 位置、實際單圖／影片／相簿傳送、接收多檔與設定後完成封面且不另發訊息。Windows 118 項相關回歸測試通過（2 項環境條件略過）；未傳送真實測試訊息。

手機 118 項相關測試也通過（Windows Docker 案例略過），程式與說明已同步並重新啟動；管理 App 與面板確認為 `1.16 / 26`。

既有安裝須同步 Python 程式（含新的 `bot/twitter_captions.py`）並重新啟動；只安裝管理 APK 不會替換程式。
