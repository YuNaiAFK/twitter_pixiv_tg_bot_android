Ignore the scratch file used to pass commit messages

_msg.txt was created for `git commit -F` on several commits and then re-added by `git add -A`,
so it kept reappearing in the tree. It is now gitignored and untracked.

Also removes the renormalize leftovers: no content change, only the line-ending bookkeeping that
`git add --renormalize .` staged while investigating why `git pull` refused to run on the phone.
The answer was not the index - it is already LF, as `git ls-files --eol` confirms with i/lf. The
phone's copy had CRLF because the file had been pushed over adb straight from a Windows working
copy, which `eol=lf` cannot fix since adb does not run git's smudge filter.
