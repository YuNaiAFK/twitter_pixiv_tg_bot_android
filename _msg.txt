Use the phone's own proxy instead of switching mirrors

A working VPN is strictly better than any mirror: it makes GitHub, pip and the TDLib source
reachable, not just the package index. The bootstrap now probes 127.0.0.1 for v2rayNG's usual
ports (10808 SOCKS5 / 10809 HTTP, plus 7890/7891) and tries BOTH protocols on each, because
guessing the wrong one looks exactly like a dead proxy.

When a proxy is found it is exported for the run, written to ~/.proxy-url, given to apt through
apt.conf.d (apt ignores the *_proxy environment variables for its own transport), and set for
github.com only in git - a global http.proxy would break the user's other repositories.

Mirror switching is now a fallback that runs ONLY when there is no proxy, and can be forced off
with --no-mirror. Switching was the wrong default for a phone that already has a VPN.

Added scripts/find-proxy.sh to test this on its own and print the exact export lines, since a
proxy that accepts a connection but carries nothing is worse than none: every tool then hangs
instead of saying so, which is what happened with apt earlier.
