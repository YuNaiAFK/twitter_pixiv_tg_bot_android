Scrub the inherited Termux paths before configuring TDLib

The build died at 3% compiling sqlite3.c with errors from Termux's Android headers:

    /data/data/com.termux/files/usr/include/android/api-level.h:201: error: 'strict' undeclared
    /data/data/com.termux/files/usr/include/sys/cdefs.h:365: #error Unversioned target triples
    /data/data/com.termux/files/usr/include/string.h:44: error: expected '=' before 'memccpy'

None of those files has anything to do with sqlite. The generated flags.make said why:

    C_INCLUDES = -I/opt/telegram-bot-api/td/sqlite -isystem /data/data/com.termux/files/usr/include

Using Debian's gcc with Termux's bionic headers cannot work. The path arrived through
pkg-config: TDLib's CMake asks it for the OpenSSL location, Termux's PKG_CONFIG_PATH was
inherited into the chroot, and pkg-config answered with the host's copy. CMakeCache.txt recorded
it in a dozen places:

    OPENSSL_INCLUDE_DIR:PATH        = /data/data/com.termux/files/usr/include
    OPENSSL_CRYPTO_LIBRARY:FILEPATH = /data/data/com.termux/files/usr/lib/libcrypto.so
    _OPENSSL_CFLAGS:INTERNAL        = -I/data/data/com.termux/files/usr/include
    _OPENSSL_PREFIX:INTERNAL        = /data/data/com.termux/files/usr

Four changes, because either half alone is not enough:

  - PKG_CONFIG_PATH, PKG_CONFIG_LIBDIR, CPATH, C_INCLUDE_PATH, CPLUS_INCLUDE_PATH,
    LIBRARY_PATH, LD_LIBRARY_PATH, LD_PRELOAD, CMAKE_*_PATH, CFLAGS and friends are unset
  - PATH is set to the chroot's own directories only, since /usr/bin/cc exists in Termux too
  - CC and CXX are pinned to /usr/bin/gcc and /usr/bin/g++, passed to cmake explicitly
  - `rm -rf build` before configuring: CMake caches its detection, so a stale cache reproduces
    the failure even after the environment is fixed

Two guards were added. pkg-config's answer for openssl is printed and rejected if it is under
/data/data/com.termux, and after configuring the build files are grepped for a Termux include
path, so this class of failure is caught in seconds instead of twenty minutes into a compile.
