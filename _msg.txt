Stop running 'pip install --upgrade pip', which Termux forbids

    $ python -m pip install --upgrade pip
    ERROR: Installing pip is forbidden, this will break the python-pip package (termux).

Termux manages pip through pkg, so upgrading it with pip desynchronises the two and Termux
blocks it. Under set -euo pipefail that refusal aborted the whole script, so the server build
never reached the chroot at all - the last thing on screen was the forbidden-upgrade error.

Two changes in setup-termux.sh:

  - the upgrade is removed; it is not needed to install the packages below, and pkg upgrade is
    the right way to move pip on Termux
  - the single bulk pip install becomes a per-package loop that checks by importing first, so a
    re-run only fetches what is genuinely absent and one failure does not skip the rest
